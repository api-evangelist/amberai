Amberai provides an AI-native operating system for global brands, enabling digital workers to automate product development, order processing, freight, payments and supplier management. The platform unifies data across ERP, logistics and finance, delivering real‑time insights and machine‑speed execution for high‑growth, high‑margin enterprises.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Amberai: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
